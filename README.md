Учебный проект по проектированию ML-сервиса на Python.

В проекте реализованы пользователь с балансом, ML-задачи, демонстрационная модель, результаты предсказаний и транзакции. 
Валидные строки обрабатываются моделью, невалидные возвращаются отдельно, а средства списываются только после успешного выполнения задачи.

Для запуска:

python main.py
